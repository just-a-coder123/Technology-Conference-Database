# Technology Conference Database

## About the Project
This project is about creating and managing a database for a technology conference using SQL. It stores information about sessions, speakers, dates, and room assignments.

## Features
- Create a database table.
- Insert new session records.
- View session details.
- Update session information.
- Add new columns.
- Assign conference rooms.
- Delete cancelled sessions.

## SQL Commands Used
- `CREATE TABLE`
- `INSERT INTO`
- `SELECT`
- `UPDATE`
- `ALTER TABLE`
- `DELETE`
- `WHERE`

## Table Structure
The `sessions` table contains the following columns:

| Column | Description |
|---|---|
| id | Session ID |
| title | Session title |
| speaker | Speaker name |
| session_date | Session date |
| room | Assigned conference room |

## Tools Used
- SQL
- SQLite
